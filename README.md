# 토익 단어

토익 빈출 단어 **1,208개**를 Day 1~60으로 나눠 외우는 웹앱입니다.
설치나 회원가입 없이 브라우저에서 바로 쓸 수 있고, 휴대폰 홈 화면에 추가하면 앱처럼 동작합니다.

👉 **바로 시작하기: https://yjefff.github.io/toeic-words/**

## 기능

- **Day별 학습**: 1,208개 단어를 60개 Day(하루 약 20단어)로 나눴습니다.
- **단어 외우기**: 뜻을 가려둔 상태로 단어를 보고, 탭하면 뜻이 나옵니다. 외운 단어는 체크해 둘 수 있습니다.
- **4지선다 테스트**: 그 Day 단어를 모두 출제합니다. 이전/다음으로 오가며 답을 고칠 수 있고, Day마다 최고 점수가 남습니다.
- **전체 랜덤 테스트**: Day와 상관없이 전체 1,208개 단어에서 무작위 20문제를 냅니다. 틀린 단어에는 몇 Day 단어인지 표시됩니다.
- **역방향 문제**: "뜻 보고 단어 고르기"를 켜면 한국어 뜻을 보고 영단어를 고르는 문제로 바뀝니다.
- **오답 노트**: 테스트에서 틀린 단어가 자동으로 모이고, 오답만 따로 다시 테스트할 수 있습니다.
- **진도 표시**: 전체·Day별로 외운 단어 수와 진행률을 보여주고, 마지막에 공부한 Day부터 이어서 할 수 있습니다.
- **오프라인 지원**: 한 번 열어두면 인터넷이 없어도 쓸 수 있습니다.

다루는 주제는 인사/채용, 사무/업무, 재무/회계, 마케팅/영업, 출장/여행/교통, 시설/건물/장비, 회의/행사, 제조/생산, 법률/정부/부동산, 보건/미디어 등 토익에 자주 나오는 12개 분야와 일반 동사·형용사·부사입니다.

## 휴대폰 홈 화면에 추가하기

- **iPhone (Safari)**: 사이트 접속 → 하단 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)**: 사이트 접속 → 우측 상단 ⋮ 메뉴 → **홈 화면에 추가** (또는 **앱 설치**)

## 학습 기록은 어디에 저장되나요?

외운 단어, 오답 노트, 테스트 점수는 모두 **내 기기의 브라우저(localStorage)** 에만 저장됩니다. 서버로 전송되지 않습니다.
그래서 다른 기기나 다른 브라우저와는 기록이 공유되지 않고, 브라우저 데이터를 지우면 기록도 함께 사라집니다.
홈 화면 맨 아래 **학습 기록 초기화** 버튼으로 직접 지울 수도 있습니다.

## 직접 실행하기

빌드 과정이 없는 순수 HTML/CSS/JavaScript 앱입니다. `words.json`을 `fetch`로 불러오기 때문에 파일을 더블클릭하지 말고 로컬 서버로 여세요.

```bash
git clone https://github.com/YJEFFf/toeic-words.git
cd toeic-words
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 단어 수정·추가

단어 데이터는 `words.json` 한 파일에 있습니다. 한 줄에 단어 하나씩, 아래 형식을 따릅니다.

```json
["applicant", "n", "지원자", "인사/채용"]
```

| 순서 | 내용 | 예시 |
|---|---|---|
| 1 | 영단어 | `applicant` |
| 2 | 품사 (`n`, `v`, `adj`, `adv`, `phr`, `prep`, `conj`, `n/v` 등) | `n` |
| 3 | 뜻 | `지원자` |
| 4 | 분류 (현재 화면에는 쓰지 않음) | `인사/채용` |

단어는 파일 순서대로 60개 Day에 고르게 나뉩니다. 단어를 바꾼 뒤 배포했다면 `sw.js`의 캐시 버전도 올려야 기존 사용자에게 새 데이터가 반영됩니다.

## 파일 구성

```
index.html      앱 진입점
app.js          화면·학습 로직 (Day 분할, 퀴즈, 오답 노트)
style.css       스타일
words.json      단어 데이터 1,208개
sw.js           오프라인 캐시용 서비스 워커
manifest.json   홈 화면 설치(PWA) 설정
icons/          앱 아이콘
```
